## 当前实验范围

公开配置 `stage_ablation` 只接受 `full`、`wo_route`、`wo_plan`、`wo_pack`，实验 JSON 的 cases 为同一四项。新建索引入口与复用索引入口使用相同 runner；两个入口表示两种索引来源。复用 Shell 当前还默认设置 `--include-hipporag --eval-mode rag_qa`，即四组 BindPack 之外增加独立的 HippoRAG 2 方法基线，并输出 QA。默认三个数据集共 15 个结果目录；这不改变 BindPack 的四项阶段枚举。

`full` 保留完整 Route、Plan、Pack 及最终 safeguard；`wo_route` 使用基础图候选适配器；`wo_plan` 跳过依赖计划、执行、绑定、proof 与 DAG package；`wo_pack` 仅保留原 base/goal pointwise 排序，关闭 greedy、DAG 和最终 safeguard。历史实验产物中的旧 case 名称保留为已有结果，不属于当前 runner 的实验枚举。

默认 LLM 为 Qwen3-8B（服务 ID `qwen3-8b`），embedding 为 `/root/models/Qwen3-Embedding-8B`。方法参数由 `configuration/defaults.json` 提供，实验资源由 `configs/ablations_qwen3.json` 提供。复用入口沿用同一份方法配置。

本次只读审查核对了三组原始 benchmark/corpus 的 SHA 与历史 manifest 一致，sample IDs 顺序一致，实际索引 passage 集合与完整 corpus 精确一致，未额外补入 gold 支持文本。graph 与 chunk/entity/fact parquet 的 SHA 均匹配历史记录；三类向量均为 4096 维，passage/entity 无缺失图节点。Qwen 编码使用 normalized、2048 截断、bf16 与原生产实现相同的 query instruction。

复用入口为 `scripts/run_bindpack_four_cases_reuse.sh`。正式结果写入源根目录的 `cases/<dataset>/<full|wo_route|wo_plan|wo_pack>/`；额外的 HippoRAG 2 结果为 `cases/<dataset>/hippporag2_reproduce/`。协议、参数快照与本批次汇总单独写入 `metadata/stage_ablations_qwen3_reuse/`。原有 case 目录、根目录历史汇总、完成标记和源索引保留。

各组从独立索引副本和独立 LLM cache 开始。源图、向量和 OpenIE 只读，运行前后校验；副本优先使用 reflink，无法使用时复制独立文件，不使用可共同修改的硬链接。每组成功校验后释放临时图/向量/OpenIE 副本，保留结果、协议、日志、请求及派生缓存；失败组保留输入以便排查。已存在且不属于本次协议的同名 case 拒绝覆盖；断点继续要求原协议、样本、代码、输入、参数与冻结资产匹配，完成组无需重复制或调用 LLM。
