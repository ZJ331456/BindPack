## 已完成的结构调整

- 公开接口只保留 `BindPack`、`BindPackConfig`，创建方式为 `BindPack(config=cfg)`，运行配置为 `rag.config`。
- `EvidencePipeline` 显式组合 `PlanStage` 和 `PackStage`；planner、executor、verifier、scorer、coverage selector、DAG selector 各有真实实现，不再依赖旧 EvidenceRetrieval/Mixin 继承链。
- Route 按 QuerySeedPrior、BridgeExpansion、IterativeRefinement、RouteRefinement 和 PathSetConsolidation 拆分，Plan/Pack 的共享工具和最终 verification 归入对应的新路径。
- `config.py` 负责配置组合、加载和校验；`configuration/defaults.json` 提供算法默认参数，按 candidates/route/plan/pack 分组，运行时通过同名嵌套对象读取。
- 删除旧导入包装、类别名、`improvement_stage`、细粒度组件 flags、旧 NV2 Shell 与历史实验 API。主入口只执行 Full、w/o Route、w/o Plan、w/o Pack。

实验资源允许在 `configs/ablations_qwen3.json` 和 CLI 中明确覆盖；算法数值从统一方法 JSON 读取。Runner 冻结方法文件内容与哈希并导出到每组结果。默认 LLM/embedding 为 Qwen3-8B/Qwen3-Embedding-8B。

## 真实 Qwen3 验证

本轮使用本地 Qwen3-8B vLLM 服务与 Qwen3-Embedding-8B GPU embedding。

冻结 Full 回放使用 8 篇短文、1 个显式 2-hop 问题和旧 LLM 响应缓存。当前版本的全部 8 篇文档顺序、8 个浮点分数、5 条已捕获 prompt，以及规范化后的完整 trace 均与旧记录精确一致；6 次 LLM 缓存命中、0 次缓存 miss、0 次新 HTTP。Fact filter 的调用计入 cache hit，但不在这 5 条捕获 prompt 内。只规范化阶段元信息与来自集合的无序 seed entity 诊断列表，算法内容保持精确比较。

记录为 `outputs/refactor_validation_v2_2026-10-18/tiny_cache_regression.json`，同目录保存前后 JSON、日志和比较脚本。Embedding 真实在 GPU 上运行，LLM 新请求被硬拒绝，未使用新响应补齐缓存。

## 效果结论边界

验证针对重构是否改变 Full 的既有计算与新入口是否跑通。8 篇 tiny corpus、1 题与合成 Pack 回放都不是正式 benchmark。在本报告对应快照完成时，三个数据集的全量 benchmark 尚未重跑；后续用户已启动的正式批次进度见最终检查说明。不能据此保证更换 embedding 后相对旧 NV-Embed-v2 的分数相同或更好，也不能预设每项消融必然下降。
